# Freqtrade on Delta Exchange (Docker)

This repository contains a production-ready setup for running Freqtrade on Delta Exchange using Docker Compose.
It supports both Dry-Run (with live data) and Live Trading modes.

## Prerequisites

- Docker & Docker Compose
- A Delta Exchange account (India or Global)
- API Keys (Trading permissions only, NO withdrawal)

## Quick Start

### 1. Bootstrap

Initialize the project structure and create your environment file:

```bash
./scripts/bootstrap.sh
```

### 2. Configure Environment

Edit the `.env` file with your Delta Exchange credentials:

```bash
DELTA_ENV=india_testnet  # Options: india_prod, global_prod, india_testnet
DELTA_API_KEY=your_api_key
DELTA_API_SECRET=your_api_secret
```

### 3. Dry Run (Recommended First Step)

Start the bot in Dry-Run mode. This will:
1.  Connect to Delta Exchange.
2.  Verify time synchronization.
3.  Fetch active Futures markets.
4.  Generate a valid whitelist (`user_data/pairlists/whitelist.delta.json`).
5.  Start the container.

```bash
./scripts/run_dryrun.sh
```

View logs:
```bash
docker compose logs -f
```

### 4. Live Trading

**WARNING: financial risk involved.**

To switch to live trading:
1.  Ensure you have tested thoroughly in Dry-Run.
2.  Run the live script:

```bash
./scripts/run_live.sh
```

It will prompt for confirmation before starting.

## Configuration Details

- **Configs**: Located in `user_data/configs/`.
    - `config.delta.dryrun.json`: Dry-run = true.
    - `config.delta.live.json`: Dry-run = false.
- **Whitelist**: Automatically generated by `scripts/update_markets_and_whitelist.sh` into `user_data/pairlists/whitelist.delta.json`.
- **Strategy**: Default is `DeltaSafeStrategy` (ensure this file exists in `user_data/strategies`).

## Troubleshooting

- **Time Drift Error**: Run `sudo ntpdate pool.ntp.org` or ensure your system clock is synced.
- **Empty Whitelist**: Check `user_data/reports/markets_*.json` to see if markets were fetched. Ensure `FILTER_MODE` in `.env` matches available pairs (default: `perps_usdt`).
- **API Errors**: Check your `DELTA_ENV` setting matches your API key (India vs Global keys are different).

## Security

- **NEVER commit your `.env` file.**
- Ensure API keys do NOT have withdrawal permissions.
